Bulk Edit

Applies one value to every selected row at once. A row where this field is read-only (e.g. % Done on a parent task) is skipped.

👤 Manage Resources

Named resources appear as a quick-pick list (the ▾ icon) when filling in the grid's Resource column. Renaming here updates every task already assigned that name; removing a name here only removes it from this list -- it doesn't clear any task already assigned it.

Dropbox is optional

Simple Gantt works fully offline with no account. Here's what changes if you sign in:

WITHOUT DROPBOX
  • Data lives only in this browser
  • No version history — only the current state exists
  • Clearing browser data loses everything, unless you've manually exported a CSV
WITH DROPBOX
  • Automatic backups ~1 min after edits stop
  • Full version history — restore any past backup
  • Projects can be found and imported on a new device
